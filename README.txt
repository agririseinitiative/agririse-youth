AGRIRISE YOUTH INITIATIVE — MULTI-PAGE WEBSITE

HOW TO OPEN
1. Download and extract AgriRise_Multi_Page_Website.zip.
2. Open the AgriRise_Website folder.
3. Double-click index.html.
4. Use the navigation menu to visit the separate pages.
